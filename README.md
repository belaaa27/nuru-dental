# Nuru Dental

**A Modern Digital Experience for Dental Care.**

## Overview

Nuru Dental is a modern dental clinic website demonstration project designed to present dental services and clinic information through a clean, welcoming, and responsive user experience.

The project focuses on clear navigation, accessible information, thoughtful layouts, and a calm visual identity suitable for a dental care website.

This is a frontend demonstration project. Clinic-specific business information should be confirmed before being treated as real operational information.

## Website Sections

The project includes the following website routes:

- **Home** — Main landing page and introduction.
- **Services** — Dental service information.
- **Team** — Team presentation.
- **FAQs** — Frequently asked questions.
- **Contact** — Contact information and enquiry section.

## Design Direction

Nuru Dental uses a calm, nature-inspired visual identity to create a welcoming and professional atmosphere.

### Design Principles

- Clean and welcoming visual presentation

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/belaaa27/nuru-dental.git
```

### 2. Navigate to the project

```bash
cd nuru-dental
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Create a production build

```bash
npm run build
```

### 6. Run ESLint

```bash
npm run lint
```
